# Стан MOTORNA — 01.11.2026

| Можливість | Стан | Межі |
|---|---|---|
| VIN → гараж | Працює | МВС snapshot, резервні декодери; часткові дані підтверджує власник |
| Деталь → пропозиції → фільтри | Працює | Лише доступні джерела; повнота та актуальність не гарантовані |
| VIN-сумісність OEM | Не підключено | Збіг артикула відокремлений від заводського підтвердження |
| Запит на купівлю, TXT | Працює | Приватна чернетка, без надсилання, оплати та резерву |
| Гараж, чеки, витрати, QR, PDF/Excel | Працює | Публічний каталог відкличний; чеки за вибором власника |
| ТО за датою або пробігом | Працює | Нагадування в гаражі, без push/SMS; пробіг вводиться вручну |
| Симптоми та OBD | Обмежений довідник | Правила, не LLM; не підтверджений діагноз |
| СТО по Україні | Працює через зовнішні джерела | Картографічні точки, маршрути й наявні контакти; не гарантія актуальності |
| Мобільні фільтри | Працює | Нижня панель до 768 px; desktop-фільтри в сторінці |
| Регресії та API-сценарій | Автоматизовано | 10 офлайн наборів; інтеграційний тест лише localhost |
| GitHub Actions | Конфігурацію додано | Windows/Node 24, install/lint/typecheck/tests/build/local API; результат віддаленого запуску перевіряється в Actions |
| ESLint | Технічний борг | 127 наявних помилок у baseline; CI блокує нові, strict-команда показує весь борг |
| Темна тема, кабінети продавців/СТО | Не реалізовано | Подальший розвиток |
| Календарі СТО, OBD-адаптери, черги, моніторинг | Не реалізовано | Окремі інтеграції та інфраструктура |
