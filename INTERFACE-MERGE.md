# Оновлення інтерфейсу — 1 жовтня 2026

Надані `*_diff` файли містять повні блоки «до/після» окремого React 18/Vite прототипу. Зміни адаптовано до чинного React 19/Vinext застосунку.

- Header, Sidebar, MobileDock: `app/workspace-navigation.tsx`; адаптивне меню з керуванням фокусом, Escape і закриттям після переходу.
- HomeWorkbench: оформлення категорій, вибір збереженого авто, збережений пошук VIN/симптомів/OEM через чинні API; фото автомобіля залишено.
- Пропозиції: `app/offer-results.tsx`, фільтри назви, магазину та ціни. Сортування цін доступне лише в одній вибраній валюті. У джерелах немає окремого перевіреного поля бренду, тому бренд можна шукати в назві; окремого вигаданого переліку брендів немає.
- GaragePage: оновлено картки та вибране авто; збережено VIN-підтвердження, редагування, серверні витрати, CSV і завантаження документів.
- FavoritesPage, ProfilePage: `app/personal-pages.tsx`; реальні записи, статистика, історія з цінами, доступ до гаража. Нові записи обраного зберігають ціну, валюту, магазин і час перевірки; старі записи без ціни підтримуються.
- ServicePage: оформлення карток і телефонів, фільтрація знайдених СТО за назвою/вулицею, сортування за дорожньою відстанню або назвою. Геокодування адреси і маршрути залишено. Рейтинги, відгуки й спеціалізації не підставляються з демонстраційних масивів.
- index.html: українська мова та метадані перенесені в `app/layout.tsx`.
- CSS: `app/interface-refresh.css`, адаптивність, видимий фокус, друк і reduced motion.
- package.json/package-lock.json: залежності іншого прототипу не замінюють наявний стек; зміна framer-motion не потрібна, бо компоненти його не використовують. Додано команди `npm run typecheck` та `npm run test:offers` без зміни дерева залежностей.

Демонстраційні автомобілі, ціни, телефони, результати та прапорці `compatible: true` не імпортовані. Підтвердження OEM-сумісності потребує даних підключеного каталогу.

Перевірено: TypeScript, production build, тести фільтрів і серверної валідації обраного, головна сторінка на десктопі та 390 px, мобільне меню і перехід у профіль. Пошук OEM у комерційних каталогах без ключа цим оновленням не перевірявся.
