# Перевірки MOTORNA

## Швидкі перевірки
- `npm run typecheck` — TypeScript без генерації файлів.
- `npm run lint` — нові помилки відносно явного baseline; залишок 95, зменшено зі 127 без вимкнення правил.
- `npm run lint:strict` — всі помилки; ще не проходить, борг не прихований.
- `npm test` — 10 регресійних наборів без зовнішніх джерел.
- `npm run build` — production build.

## API
Запустіть локальний dev-сервер і `npm run test:api`. Перевіряються збережений VIN, діагностика, приватний запит, повторне читання, TXT, відмова анонімному користувачу, чужому carId та demo-товарам. Видаляються тільки записи цього тесту. Запуск проти віддаленого домену заборонений у тесті.

## Playwright E2E
Після `npm ci` встановіть Chromium: `npx playwright install chromium`. Запуск: `npm run test:e2e`. Сервер запускається й завершується засобами Playwright; локальний уже запущений сервер можна повторно використати. В CI повторне використання вимкнено. Використовується тільки localhost і локальна тестова ідентичність Sites. Production-ключі та облікові записи не потрібні.

Три сценарії для desktop 1440×1000 і mobile 375×812:
1. VIN → підтвердження авто → артикул → фільтр виробника → непідтверджена сумісність → кількість → приватний запит → reload → TXT. Demo-пропозиція не додається.
2. HTTP 503 від джерела → відсутність вигаданих товарів/цін → запит на підбір без ціни.
3. Перемикання авто в гаражі → попереднє QR-посилання та зображення не переносяться до іншого авто.

Зовнішні відповіді VIN, фотографій та магазинів у браузерних тестах — контрольовані фікстури. Третій сценарій додатково підміняє відповідь QR-API лише для перевірки ізоляції стану. Тести не підтверджують доступність продавця, справжню ціну або OEM-сумісність. Авторизація, записи, валідація власника та TXT працюють через справжній локальний сервер і базу. Тестові записи очищаються за власними VIN; чужі записи не видаляються. У робочому застосунку немає умовних E2E-обходів прав доступу.

`playwright-report/` містить HTML-звіт; `test-results/` — скріншоти успіху та traces помилок. Вони ігноруються Git. Actions завантажує звіт з обмеженим строком зберігання 7 днів. Запуски не публікують сайт. Для production потрібна окрема перевірка зовнішніх API без заміни відповідей.

Конфігурація: `playwright.config.ts`, `tests/e2e/purchase.spec.ts`, `.github/workflows/ci.yml`. Тайм-аути враховують холодну компіляцію dev-сервера; фіксованих sleep у браузерних тестах немає.
