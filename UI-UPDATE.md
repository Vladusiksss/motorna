# Оновлення інтерфейсу — 30.09.2026

Застосовано: світлий адаптивний інтерфейс, бічне меню й мобільна навігація, спільний пошук VIN/деталі/OEM/симптомів/СТО, підказки назв, категорії, інтерактивна умовна схема вузлів, короткий гід, гараж на головній, збереження вибору авто на пристрої, пропозиції з історії, розкривна інформація про сумісність.

Збережено: локальна база МВС, AI-діалог, реальні пропозиції продавців, пошук СТО за адресою, контакти, історія обслуговування й документи.

Не повернуто за попередніми побажаннями: калькулятор, кошик, плани покупок, пошук за держномером.

Не реалізовано: OCR/розпізнавання фото, точні 3D-схеми моделей, живий оператор, партнерське онлайн-бронювання, перевірені відгуки, історія ринкових цін. Для частини потрібні додаткові моделі, накопичені дані або підключення партнерів. Відкриті дані МВС не містять каталожної застосовності деталей; точне підтвердження VIN → OEM досі потребує постачальника OEM-даних. Декоративні рейтинги, ціни, гарантії та бейджі не вигадуються.
