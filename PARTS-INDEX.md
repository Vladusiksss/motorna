# Parts Index
Документація: https://api.parts-index.com/docs/ru/openapi.yml (OpenAPI 1.2.0).

Реалізовано: вибране авто користувача → VIN → /v1/parts-by-vin/cars?q= → вибір модифікації → /v1/parts-by-vin/cars/{carId}/results → артикул → пошук магазинів.

Для запуску потрібен ключ із правами access, parts-by-vin.cars, parts-by-vin.results. Збережіть точне значення заголовка Authorization у локальний файл .parts-index-key (один рядок, без лапок). Файл виключений із Git. Не використовуйте NEXT_PUBLIC_ і не надсилайте ключ у чат. Перезапустіть локальний вебсервер через Start-Local.ps1. Альтернатива — серверна змінна PARTS_INDEX_API_KEY.

Ключ передається тільки сервером на https://api.parts-index.com. VIN береться з авто поточного користувача. Клієнт не може підставити довільний provider carId; він обирає варіант у серверному сеансі. pending/in_progress не видаються за готовий список; доступне оновлення. Без ключа запит до провайдера не виконується.

Список каталогу і збіг артикула продавця не є автоматичним доказом сумісності будь-якого аналога. Поточні картки магазинів зберігають статус непідтвердженої сумісності. Жива перевірка потребує ключа; тестові відповіді не відображаються користувачам.
