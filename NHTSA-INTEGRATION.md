# NHTSA vPIC — 2 жовтня 2026

VIN розшифровує серверний `/api/vehicle` через офіційний DecodeVinValuesExtended без API-ключа. МВС більше не є джерелом цього маршруту. Режим призначено для авто американського ринку; країна складання не обмежується США. Наявність декодування сама по собі не є доказом історії імпорту чи продажу в США.

Приймається VIN із 17 символів, відповідь із ErrorCode=0 та непорожніми маркою, моделлю й роком. Часткові/помилкові відповіді відхиляються. Невідомі двигун, комплектація, колір не вигадуються. vPIC не містить OEM-каталогу запчастин і не підтверджує сумісність.

`app/vpic.ts`: 18-секундний тайм-аут, об'єднання одночасних запитів одного VIN, кеш успішних результатів у `vin_decode_cache` на 7 днів. Таблиця створюється ідемпотентно при першому зверненні, VIN — первинний індекс. Прострочені результати оновлюються при наступному запиті; помилки не кешуються. Якщо кеш недоступний, залишається прямий запит. Пошук деталей повторно перевіряє VIN збереженого авто та використовує марку, модель, рік і двигун vPIC замість довільно введених характеристик.

Комерційні каталоги залишаються окремими інтеграціями з власними ключами. Порожній `.parts-index-key` не створюється: він не дасть доступу. Повідомлення постачальникам не надсилалися. Імпорт прайсів, конвертація валют і нормалізація брендів — окремі задачі; у поточному сховищі немає таблиці магазинних прайсів для індексу OEM+brand+store.

Документація: https://vpic.nhtsa.dot.gov/api/
Перевірка: `node --experimental-strip-types tests/vpic.mjs`.
